# Turov_Akhmadiev

## Краулер

1. Файл **`index.txt`** формируется с помощью скрипта **`links_generator.py`**.  
   Скрипт собирает ссылки на статьи с сайта https://elementy.ru и сохраняет их в `index.txt`.

2. Краулер:
   - считывает ссылки из файла **`index.txt`**;
   - загружает содержимое каждой страницы;
   - сохраняет полученные файлы в директорию **`downloads`**.

---

## Обработка текстов и лемматизация

1. Скрипт:
   - считывает текстовые файлы из директории **`downloads`**;
   - очищает содержимое от HTML-разметки, спецсимволов и лишних пробелов;
   - приводит текст к нижнему регистру.

2. Обработка текста:
   - выполняется токенизация текста (разбиение на слова);
   - удаляются стоп-слова русского языка;
   - оставляются только корректные русские слова;
   - выполняется морфологический разбор слов;
   - отбрасываются слова с низкой вероятностью распознавания.

3. Результат:
   - формируются файлы **`...tokens.txt`** — список уникальных токенов;
   - формируются файлы **`...lemmas.txt`** — словарь лемм, где каждой нормальной форме соответствует список словоформ.

---

## Построение инвертированного индекса

1. Скрипт **`index_builder.py`** строит инвертированный индекс на основе файлов лемм.

2. Источник данных:
   - используются файлы формата **`*_lemmas.txt`** из директории **`lemmas`**;
   - каждый файл соответствует отдельному документу;
   - имя документа определяется из имени файла (без суффикса `_lemmas`).

3. Алгоритм построения:
   - создаётся структура `defaultdict(set)`;
   - для каждого файла:
     - считываются строки;
     - извлекается лемма (первый элемент строки);
     - лемма приводится к нижнему регистру;
     - идентификатор документа добавляется в множество документов для данной леммы.

4. Структура индекса:
   лемма → {doc_id1, doc_id2, ...}

5. Сохранение:
- множества преобразуются в списки для сериализации;
- индекс сохраняется в файл **`inverted_index.json`** в формате JSON.

6. Результат:
- формируется файл **`inverted_index.json`**, содержащий инвертированный индекс.

---

## Булев поиск по инвертированному индексу

1. Скрипт **`boolean_searcher.py`** реализует поиск по построенному индексу.

2. Поддерживаемые логические операторы:
- `AND` — пересечение множеств документов;
- `OR` — объединение множеств документов;
- `NOT` — дополнение множества относительно всех документов;
- поддерживаются скобки `(` `)` для задания приоритета операций.

---

### Этапы обработки запроса

#### 1. Загрузка индекса

- файл **`inverted_index.json`** считывается;
- списки документов преобразуются обратно в множества (`set`) для эффективных операций.

---

#### 2. Токенизация запроса

Функция `tokenize()`:
- разбивает строку запроса на леммы, логические операторы и скобки;
- операторы приводятся к верхнему регистру.

Пример запроса:
   (физика AND энергия) OR NOT атом

---

#### 3. Преобразование в постфиксную форму

Функция `to_postfix()` реализует алгоритм сортировочной станции (Shunting Yard):

Приоритет операторов:
- `NOT` — 3
- `AND` — 2
- `OR` — 1

Результат — выражение в постфиксной форме для удобного вычисления.

---

#### 4. Вычисление выражения

Функция `evaluate_postfix()`:
- использует стек;
- при встрече:
  - `AND` — выполняется пересечение множеств;
  - `OR` — выполняется объединение;
  - `NOT` — выполняется дополнение относительно множества всех документов;
  - леммы — извлекается множество документов из индекса.

---
