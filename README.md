# Turov_Akhmadiev

Поисковая система по русскоязычным научным статьям с сайта [elementy.ru](https://elementy.ru).

---

## Установка и запуск

### Зависимости

```bash
conda env create -f environment.yml
conda activate morpho
```

Или через pip:

```bash
pip install beautifulsoup4 nltk pymorphy3 requests flask
```

### Пайплайн обработки данных

Скрипты выполняются последовательно:

```bash
# 1. Генерация ссылок на статьи
python links_generator.py

# 2. Скачивание статей
python crawler.py

# 3. Токенизация и лемматизация
python lemmatizer.py

# 4. Построение инвертированного индекса
python index_builder.py

# 5. Вычисление TF-IDF
python tf_idf_counter.py
```

### Поиск

```bash
# Булев поиск (консольный)
python boolean_searcher.py

# Векторный поиск (консольный)
python vector_search.py

# Векторный поиск (веб-интерфейс)
python web_search.py
# Открыть http://localhost:5000
```

---

## Краулер

1. Скрипт **`links_generator.py`** формирует файл **`index.txt`** — список ссылок на статьи с сайта https://elementy.ru.

2. Скрипт **`crawler.py`**:
   - считывает ссылки из **`index.txt`**;
   - загружает содержимое каждой страницы;
   - сохраняет файлы в директорию **`downloads/`**.

---

## Обработка текстов и лемматизация

Скрипт **`lemmatizer.py`**:

1. Считывает текстовые файлы из **`downloads/`**.
2. Очищает от HTML-разметки, спецсимволов; приводит к нижнему регистру.
3. Выполняет токенизацию, удаляет стоп-слова, оставляет только корректные русские слова.
4. Выполняет морфологический разбор (pymorphy2), отбрасывает слова с низкой вероятностью распознавания (score < 0.5).

Результат:
- **`tokens/<doc>_tokens.txt`** — список уникальных токенов;
- **`lemmas/<doc>_lemmas.txt`** — словарь лемм (формат: `лемма форма1 форма2 ...`).

---

## Построение инвертированного индекса

Скрипт **`index_builder.py`**:

1. Читает файлы **`*_lemmas.txt`** из **`lemmas/`**.
2. Для каждой леммы собирает множество документов, в которых она встречается.
3. Сохраняет индекс в **`inverted_index.json`** (формат: `лемма → [doc_id1, doc_id2, ...]`).

---

## Булев поиск

Скрипт **`boolean_searcher.py`** — консольный поиск по инвертированному индексу.

Поддерживаемые операторы:
- `AND` — пересечение множеств документов;
- `OR` — объединение множеств документов;
- `NOT` — дополнение относительно всех документов;
- скобки `(` `)` для задания приоритета.

Алгоритм: токенизация запроса → преобразование в постфиксную форму (Shunting Yard) → вычисление на стеке.

Пример запроса:
```
(физика AND энергия) OR NOT атом
```

Для выхода: `exit`

---

## TF-IDF

Скрипт **`tf_idf_counter.py`** вычисляет TF-IDF для токенов и лемм.

Формулы:
- `TF = количество_вхождений / всего_терминов_в_документе`
- IDF для токенов: `log(N / (1 + DF))`
- IDF для лемм: `log(1 + N / (1 + DF))`

Результат:
- **`tfidf/<doc>_terms.txt`** — TF-IDF по токенам;
- **`tfidf/<doc>_lemmas.txt`** — TF-IDF по леммам.

Формат строки: `термин IDF TF-IDF`

## Векторный поиск

### Консольный интерфейс

Скрипт **`vector_search.py`** реализует поиск по корпусу с ранжированием на основе TF-IDF и косинусного сходства.

Алгоритм:
1. **Загрузка корпуса** — для каждого документа загружаются предвычисленные TF-IDF значения из `tfidf/` (результат работы `tf_idf_counter.py`).
2. **Обработка запроса** — текст запроса очищается, токенизируется, лемматизируется (pymorphy3), строится TF-IDF вектор (TF по запросу, IDF из корпуса).
3. **Ранжирование** — вычисляется косинусное сходство между вектором запроса и вектором каждого документа:
   ```
   cos(q, d) = (q · d) / (|q| × |d|)
   ```
4. **Результат** — топ-10 документов, отсортированных по убыванию score.

### Веб-интерфейс

Скрипт **`web_search.py`** — Flask-приложение с веб-интерфейсом для векторного поиска.

Запуск:
```bash
python web_search.py
```

Открыть в браузере: **http://localhost:5000**

Функции:
- поле ввода поискового запроса на русском языке;
- ранжирование документов по косинусному сходству;
- вывод топ-10 результатов с указанием score и ссылки на оригинальную статью на elementy.ru.

## Структура проекта

```
├── links_generator.py       # Генерация ссылок на статьи
├── crawler.py               # Скачивание статей

├── index_builder.py         # Построение инвертированного индекса

├── boolean_searcher.py      # Булев поиск (консольный)
├── vector_search.py         # Векторный поиск (консольный)
├── web_search.py            # Векторный поиск (веб-интерфейс)
├── templates/
│   └── index.html           # HTML-шаблон веб-интерфейса
├── index.txt                # Список ссылок на статьи
├── inverted_index.json      # Инвертированный индекс
├── downloads/               # Скачанные HTML-страницы
├── tokens/                  # Токены документов
├── lemmas/                  # Леммы документов
├── tfidf/                   # Результаты TF-IDF
└── environment.yml          # Conda-окружение
```
